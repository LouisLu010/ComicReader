# ComicReader 产品需求文档

## 文档状态

- 产品：ComicReader（临时工程名）
- 平台：仅 iPadOS
- 最低版本：iPadOS 17
- 发布方式：公开 GitHub 仓库，通过 GitHub Actions 构建未签名 IPA
- 许可证：MIT License
- 商业模式：免费，无广告、无行为追踪
- 状态：需求已确认，可进入分阶段实施

## Problem Statement

用户拥有以文件夹形式保存的本地漫画。一本漫画可能直接包含图片，也可能包含“卷 → 话 → 图片”等任意深度的目录结构。现有阅读流程需要用户手动整理、判断章节和维护页序，而且常见阅读器对 iPad 横屏、双页、外部文件来源及大型书库的支持不足。

用户需要一款专注于 iPad 的本地漫画阅读器：能够从“文件”App 可访问的位置导入漫画文件夹，自动识别卷、话、图片格式与顺序，将内容可靠地复制到 App 管理的资料库，并提供流畅、可恢复、保护隐私的阅读体验。

## Solution

ComicReader 使用系统文件选择器或拖放接收一个或多个漫画根文件夹。每个顶层文件夹默认代表一本漫画；任何直接包含图片的目录识别为一话，中间目录保留为卷或分组。图片格式根据文件内容识别，不依赖扩展名。

导入前展示识别预览，确认封面、目录结构、排序、异常文件及所需空间。确认后，将原图按字节复制到 App 管理的本地资料库，并以可恢复事务完成导入。漫画图片只保存在当前设备；阅读进度、收藏、元数据及设置可通过 iCloud 同步。

阅读器提供纵向连续滚动、横向单页翻页和横屏双页 3 种模式，支持从左向右或从右向左阅读、渐进图片加载、缩放、留白裁切、章节衔接和精确进度恢复。

## Goals

1. 无需预先整理即可可靠识别常见文件夹漫画结构。
2. 导入过程可预览、可取消、可恢复，不因单个坏文件破坏整本漫画。
3. 在大型书库和超大图片场景下保持稳定、流畅和可预测。
4. 充分利用 iPad 的横屏、双页、多窗口、键盘、触控板和多任务能力。
5. 本地优先，网络和 iCloud 故障不影响核心导入与阅读能力。
6. 不改变或删除用户原始文件夹中的任何内容。

## Functional Requirements

### Folder Recognition

- 每个被选择的顶层文件夹表示一本漫画。
- 任意直接包含至少一个候选图片文件的目录表示一话。
- 不直接包含图片的中间目录表示卷或分组，并保留相对层级。
- 根目录图片按同一规则生成单话；已识别为封面的图片从该话中排除。
- 空目录不生成节点。
- 隐藏文件、系统文件、软链接和文件夹别名不参与扫描。
- 非图片文件被忽略并进入报告。
- 首版不识别 PDF、ZIP、CBZ、RAR 或在线内容。

### Image Recognition

- 使用文件签名和系统解码能力判断格式，不信任扩展名。
- 支持 JPEG、PNG、WebP、HEIC／HEIF、GIF 首帧、BMP 和 TIFF。
- 尊重图片方向元数据，原文件保持不变。
- 相同内容的不同文件不自动去重，仅提示疑似重复。
- 部分损坏时保留页序并显示错误占位；整话无可读页时不创建章节。

### Ordering

- 名称排序使用数字感知的自然排序，忽略大小写并遵循系统区域设置。
- 用户可反转整话或拖动单页调整。
- 自定义显示名称和页序不改变来源相对路径与原文件名。

### Cover Selection

1. 根目录中基础名称为 `cover`、`folder` 或 `封面` 的可读图片。
2. 根目录排序后的第一张可读图片。
3. 第一话的第一页。

用户可在导入预览或漫画详情中覆盖自动结果。

### Import and Update

- 复制前扫描结构、验证可读性、计算总大小及约 10% 临时余量。
- 空间不足时不启动导入，并显示缺少容量。
- 原图按字节复制，缩略图和低分辨率预览作为可重建缓存独立保存。
- 导入使用暂存区、校验和原子提交；失败不得破坏已完成数据。
- 再次导入同一来源时执行增量更新；新章节加入，修改章节验证后替换。
- 来源中缺失的章节默认保留，用户可从报告主动清理。
- 不同来源不因同名自动合并。
- 自动检查来源更新默认关闭。

### Reader

- 支持连续纵向、横向单页和双页 3 种模式。
- 双页布局以窗口宽度决定；宽高比大于等于 1.2 的横向图默认作为单独跨页。
- 封面在双页模式中单独显示。
- 支持左右阅读方向，全局默认可被单本设置覆盖。
- 支持中心工具栏、左右点击翻页、双击缩放、捏合缩放和放大后拖动。
- 支持页码、进度条、缩略图带、章节列表及上一话／下一话导航。
- 使用低分辨率预览和邻页自适应预加载，避免整话一次性解码。
- 连续模式默认无缝衔接章节；分页模式通过章节结束页进入下一话。
- 显示设置仅影响渲染，不修改原图。

### Progress

- 保存漫画、章节、页面稳定标识、页面内偏移、缩放和更新时间。
- 最后一页末尾自动标记章节已读，支持手动已读／未读。
- 云端最近位置按更新时间更新；已读集合默认只合并不回退。
- 手动标记未读视为明确覆盖操作并同步。

### Library

- 提供继续阅读、全部、最近导入、收藏、已读／未读及自定义书架。
- 支持网格、列表、搜索、筛选和排序。
- 元数据包含标题、作者、简介、标签、阅读状态、收藏和自定义封面。
- 显示名称可编辑，来源相对路径和内部 ID 保持稳定。
- 删除先进入最近删除，30 天后永久清理；用户可立即永久删除。

### Sync and Privacy

- 漫画图片与缓存不通过 iCloud 同步，也排除在 iCloud 设备备份之外。
- iCloud 仅同步元数据、书架、收藏、阅读状态、进度和设置。
- 无 iCloud 时本地功能完整可用，恢复后自动合并。
- 使用稳定元数据 ID 或内容清单指纹匹配跨设备漫画；低置信度必须询问用户。
- 使用 iPadOS 数据保护，不创建私有图片加密格式。
- 支持可选 Face ID／设备密码锁，多任务快照在锁定时模糊。
- 不收集行为分析；仅遵循系统授权接收匿名崩溃与性能信息。

### Platform Experience

- 仅支持 iPad，不支持 iPhone 或 Mac Catalyst。
- 支持横竖屏、Split View、Stage Manager、多窗口、外接显示器、键盘和触控板。
- 支持简体中文和英文界面；所有用户内容支持 Unicode。
- 支持 VoiceOver、Dynamic Type、高对比度和降低动态效果。
- 首次启动使用空书库引导，并提供可选的原创示例漫画。

## Non-Functional Requirements

### Performance

- 产品不设置书库、章节或页面硬上限。
- 验收数据集至少覆盖 1,000 本漫画、单本 2,000 话、单话 1,000 页及总计 100,000 张图片。
- 列表、网格、章节和图片全部懒加载。
- 解码、哈希、复制、缩略图和索引不得阻塞主线程。
- 内存告警时主动释放解码缓存，原图始终可重新加载。

### Reliability

- 导入、章节替换和数据库迁移均不可留下半提交状态。
- 数据库迁移失败时不得自动清库。
- 图片与索引分离，索引损坏时可通过内部文件重建。
- 单本导入失败不得中断同批其他漫画。

### Security

- 不在日志、诊断或 CI 产物中包含漫画图片、漫画名称或用户绝对路径。
- 不引入广告、追踪或隐式联网依赖。
- 第三方依赖必须许可证兼容、固定版本并记录清单。

## Implementation Decisions

- 使用 Swift 与 SwiftUI 构建 iPad 原生界面，必要时使用 UIKit、ImageIO 和 Uniform Type Identifiers。
- 使用 SwiftData 保存本地模型，并通过 CloudKit 同步受支持的轻量元数据。
- 漫画原图存储在 App 管理目录中，数据库只保存相对位置、标识和索引信息。
- 使用 security-scoped bookmark 保存来源身份；来源失效时由用户重新授权。
- 使用文件内容摘要、相对路径和来源身份区分增量更新、跨设备匹配及不同版本。
- 导入采用 Scan → Preview → Copy → Verify → Commit 状态机。
- 可恢复任务清单持久化，App 重启后从未完成工作项继续。
- 阅读渲染使用降采样、缩略预览、邻页预取和内存自适应缓存。
- UI 使用自适应侧边栏、工具栏和多窗口 Scene，不锁定设备方向。
- 第三方 Swift Package 仅在系统框架无法满足需求时引入。
- GitHub Actions 不包含签名凭据，不执行签名、上传或安装。

## Testing Decisions

测试只验证外部可观察行为，不绑定私有实现细节。当前仓库为空，没有可复用的既有测试模式；首个里程碑将建立统一 Fixture Builder，作为识别、导入、更新和恢复的主要测试接缝。

### Highest-Level Test Seams

1. **Folder Import Use Case**：输入临时目录树和导入策略，观察识别清单、事件、持久化结果及文件副本。
2. **Reader Session**：输入漫画清单、窗口尺寸和用户操作，观察页面布局、导航及进度事件。

## Acceptance Criteria

- 用户可导入包含任意层级卷／话目录的一本或多本漫画，预览结果与规则一致。
- 改错扩展名的支持图片仍能识别；坏图不会导致整本导入失败。
- 导入中断后可继续，已完成漫画和章节不会被破坏。
- 同一来源重新导入能新增和替换章节，不自动删除缺失章节。
- 3 种阅读模式在横竖屏和多任务窗口中正确工作。
- 关闭并重新打开 App 后能恢复到准确页面和页面内位置。
- 书库达到验收规模时仍可交互，滚动和翻页不因同步解码阻塞。
- 未登录 iCloud 或网络断开时，本地导入和阅读完全可用。
- 永久删除只影响 App 内副本，不修改来源目录。
- GitHub Tag 工作流可产出未签名 IPA、dSYM 和可追溯构建信息。

## Out of Scope

- iPhone、Android、visionOS 和 Mac Catalyst。
- PDF、ZIP、CBZ、RAR 等文档或压缩包导入。
- 在线漫画源、网页抓取、下载器、内容商店和账号系统。
- OCR、全文搜索、自动图片描述和翻译。
- Apple Pencil 绘画批注、页面书签和文字笔记。
- 图片转码、锐化、调色和写回原文件。
- 自建加密容器、隐藏漫画和伪装图标。
- App Store 上架、签名、证书管理和自动安装。
- 行为分析、广告和用户画像。
